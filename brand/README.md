# Marca PSVP

Este diretório reúne os artefatos práticos da identidade da Paróquia São Vicente de Paulo.

## Arquivos principais

- [`BRAND-BOOK.md`](BRAND-BOOK.md) — essência, cores, tipografia, tom de voz e uso visual.
- [`SOCIAL-MEDIA-GUIDE.md`](SOCIAL-MEDIA-GUIDE.md) — regras para Instagram, Stories, carrosséis e Canva.
- [`CANVA-TEMPLATES.md`](CANVA-TEMPLATES.md) — lista de templates a criar e manter no Canva.

## Artefatos técnicos relacionados

- [`../tokens/tokens.css`](../tokens/tokens.css) — tokens CSS da identidade.
- [`../brand-book.html`](../brand-book.html) — versão visual navegável do brand book.
- [`../site/src/index.css`](../site/src/index.css) — tokens aplicados no site React/Vite.

## Regra de manutenção

Toda mudança de cor, fonte, tom de voz ou padrão de publicação deve atualizar primeiro estes documentos. Depois disso, o site e os templates Canva devem ser ajustados para refletir a decisão.
