# Templates Canva — PSVP

Estes arquivos são referências visuais para recriar os templates no Canva.

## Como usar

1. Abra o arquivo HTML no navegador.
2. Use o layout como referência visual.
3. No Canva, crie um design com a dimensão indicada.
4. Copie cores, hierarquia, espaçamentos e áreas editáveis.
5. Trave elementos fixos da marca e deixe editáveis apenas texto, data, horário, local e foto.
