# Templates Canva — PSVP

Este arquivo lista os templates recomendados para criar no Canva e compartilhar com a equipe da Pastoral da Comunicação.

Os previews HTML ficam em [`canva-templates/`](canva-templates/). Eles servem como referência visual para recriar os modelos no Canva.

## Templates Essenciais

| Template | Formato | Uso |
|---|---|---|
| Post de evento | 1080x1080 | Retiros, encontros, festas, missas especiais |
| Story de aviso | 1080x1920 | Lembretes e avisos rápidos |
| Programação semanal | 1080x1920 | Missas, confissões, secretaria, eventos |
| Carrossel de formação | 1080x1350 | Catequese, sacramentos, evangelho |
| Campanha do dízimo | 1080x1080 | Dízimo, prestação de contas, generosidade |
| Thumbnail YouTube | 1280x720 | Missas, lives, formações |
| Banner do site | 1920x800 | Slides do carrossel da home |

## Regras Para Montagem

- Travar cores e fontes no template.
- Deixar editáveis apenas texto, data, horário, local e foto.
- Criar uma página de instruções dentro de cada template.
- Usar nomes claros: `PSVP - Post Evento`, `PSVP - Story Aviso`.
- Guardar tudo na pasta Canva `PSVP — Templates`.

## Conteúdo Fixo

Cada template deve ter:
- Assinatura "Paróquia São Vicente de Paulo".
- Monograma `PSVP` ou assinatura tipográfica.
- Paleta burgundy, dourado e creme.
- Área reservada para data/horário quando o formato pedir.
